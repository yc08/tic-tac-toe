# Tic‑Tac‑Toe — Unbeatable Bot

A compact browser Tic‑Tac‑Toe game featuring an unbeatable AI and a simple, responsive UI.

## Features

- Strong AI that searches the game tree to make optimal moves.
- Computer randomizes between equally good moves to vary play.
- Responsive UI with end-game animations (confetti and board shake).
- Human plays as O; computer plays as X by default. Computer starts new games by default.

## How to run

1. Open `index.html` in any modern browser (double-click or open from the browser).
2. Click an empty square to place your O.
3. Use the `Reset` or `New Game (computer starts)` buttons to restart.

## Controls & behavior

- Click a cell to place your O.
- The computer responds automatically after a brief delay.
- On draw or computer win, simple animations are shown.
